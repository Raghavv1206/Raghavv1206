#### 🎯 [AdVision – Multi-Modal Generative AI Advertising Platform](https://github.com/Raghavv1206/Advision) &nbsp; [![Live Demo](https://img.shields.io/badge/Live_Demo-Vercel-000?style=flat-square&logo=vercel)](https://advision-frontend.vercel.app/) [![Repo Stars](https://img.shields.io/github/stars/Raghavv1206/Advision?style=flat-square&color=818cf8)](https://github.com/Raghavv1206/Advision)
- Multi-modal GenAI ad suite generating copy via **DeepSeek V3.1** and creative visuals via **Stability AI / Pollinations.ai** across 5+ social platforms.
- Real-time campaign telemetry featuring **chi-square A/B testing (p < 0.05)**, **7-day conversion forecasting using scikit-learn Linear Regression**, and automated ROAS optimization.
- Secured API credentials using **Fernet cryptography** and distributed assets across global **Cloudinary CDN**.
- **Stack**: `Python` · `Django REST` · `PostgreSQL` · `DeepSeek` · `Stability AI` · `scikit-learn` · `React` · `Cloudinary`

#### ☕ [Get Me A Chai (v2) – AI-Powered Creator Crowdfunding Platform](https://github.com/Raghavv1206/get-me-a-chai-version-2) &nbsp; [![Live Demo](https://img.shields.io/badge/Live_Demo-Vercel-000?style=flat-square&logo=vercel)](https://raghavs-get-me-a-chai.vercel.app/) [![Repo Stars](https://img.shields.io/github/stars/Raghavv1206/get-me-a-chai-version-2?style=flat-square&color=818cf8)](https://github.com/Raghavv1206/get-me-a-chai-version-2)
- High-concurrency creator monetization ecosystem with per-creator **Razorpay payments**, **HMAC-SHA256 signature verification**, and recurring subscriptions.
- Integrated **10 AI endpoints via OpenRouter** for automated campaign storytelling, funding milestone planning, and content moderation.
- Interactive canvas-based scrollytelling animations, **Zod schema validation**, and comprehensive creator analytics with PDF/CSV export.
- **Stack**: `Next.js 15` · `React 19` · `TypeScript` · `MongoDB` · `Tailwind CSS 4` · `OpenRouter (DeepSeek)` · `Razorpay`

#### 💡 [PromptPal – AI Prompt Engineering & 3D Interactive Studio](https://github.com/Raghavv1206/PROMPTPAL) &nbsp; [![Repo Stars](https://img.shields.io/github/stars/Raghavv1206/PROMPTPAL?style=flat-square&color=818cf8)](https://github.com/Raghavv1206/PROMPTPAL)
- Intelligent prompt experimentation workspace built with **Next.js 15.5**, **React 19.1**, and interactive **Spline 3D WebGL** runtime animations.
- Multi-model evaluation workflows leveraging **OpenAI API** pipelines for prompt optimization, few-shot generation, and benchmarking.
- Real-time latency tracking, token economy analysis, and interactive telemetry powered by **Recharts** and **Framer Motion**.
- **Stack**: `Next.js 15` · `React 19` · `TypeScript` · `OpenAI API` · `Spline 3D` · `MongoDB` · `Framer Motion`

#### 💊 [MediMate AI – Intelligent Medication Adherence & Multi-Tier Escalation Platform](https://github.com/Raghavv1206/Medimate-AI) &nbsp; [![Repo Stars](https://img.shields.io/github/stars/Raghavv1206/Medimate-AI?style=flat-square&color=818cf8)](https://github.com/Raghavv1206/Medimate-AI)
- Zero-friction healthcare adherence platform operating directly over conversational **WhatsApp Cloud API** with 1-tap quick replies (`1` Taken, `2` Snooze, `3` Skip).
- Automated **3-Tier Fail-Safe Escalation Pipeline**: T+00m WhatsApp reminder → T+15m nudge → T+45m Caretaker alert → T+75m carrier-grade **Twilio automated voice robocall** (`Polly.Aditi`).
- Explainable **5-Factor Deterministic Clinical Risk Engine (0–100)** with 7-day predictive adherence forecasts and **Meta Llama 3.3 70B** duplicate active ingredient/overdose checking.
- **Stack**: `Python` · `Django 5.0` · `React 19` · `Vite` · `Tailwind CSS 4` · `PostgreSQL` · `WhatsApp Cloud API` · `Twilio Voice` · `Meta Llama 3.3`
